# Laporan

Pemilik → **Laporan** →

- **Rentang tanggal** — pilih Dari/Sampai (ekspor memakai rentang ini).
- **Metrik live** — okupansi, anggota aktif, stok menipis; refresh tiap 10 detik, mengabaikan tanggal.
- **Rincian** — pendapatan, deposit diterima/diterapkan/dikembalikan/ditahan/hangus, per paket/produk/anggota/metode pembayaran.
- **Filter lanjutan** — kasir, metode pembayaran, paket, produk, ID anggota.
- **Ekspor** — CSV rentang terpilih (offline, host lokal).

Semua data tetap di PC Host — tanpa internet.
