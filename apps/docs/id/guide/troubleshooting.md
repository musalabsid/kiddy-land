# Troubleshooting

**Banner IP Host berubah** → scan ulang QR (lihat Jaringan).

**Kamera tidak terbuka di desktop** → scan di HP/tablet saja. Atau input token manual.

**HP untrusted cert** → Advanced → Proceed (self-signed lokal).

**"Venue in grace period — no entry"** → kalender tutup, grace 60m.
