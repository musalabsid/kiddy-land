# Mulai Cepat (5 menit)

1. **Install aplikasi Host** di PC Owner — unduh dari
   [GitHub Releases](https://github.com/musalabsid/kiddy-land/releases) (lihat Instalasi).
2. **Jalankan** → buat akun Owner → **Host Overview** terbuka.
3. **Stabilkan IP Host** → lihat Jaringan → IP Statis Windows _atau_ Reservasi Router.
   Ini mencegah `192.168.1.x` berubah (ponsel akan kehilangan koneksi).
4. **Pairing perangkat**: Host Overview → Pair Device → pilih Cashier/Scanner/Kiosk → Show QR.
5. Di ponsel/tablet: buka `https://<ip-host>:43118` (terima peringatan sertifikat sekali)
   atau scan QR dari layar Login → ter-pair.
6. **Penjualan pertama**: Cashier → New Sale → pilih paket → Add → Complete → scan tiket
   lalu serahkan ke pengunjung.

Siap digunakan.
