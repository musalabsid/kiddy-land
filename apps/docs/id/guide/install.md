# Instalasi

## Windows

1. Download `Kiddy-Land_0.1.0_x64_en-US.msi` dari GitHub Releases.
2. Double-click → Next → Finish. Ikon muncul: **Kiddy Land — Local Operation Center**.
3. Buka. Pertama kali membuat folder data `%APPDATA%\\KiddyLand` dan sertifikat HTTPS.
4. Buat akun Owner (saat pertama) → masuk ke Host Overview.

## Linux (Ubuntu/Debian)

```bash
sudo apt install ./kiddy-land_0.1.0_amd64.deb
```
Lalu buka dari launcher.

## Setelah install — lanjut ke Setup Jaringan!

> Jika HP menampilkan "sertifikat tidak tepercaya", tap **Advanced → Proceed** sekali. Sertifikat self-signed untuk jaringan lokal dan aman.
