# Selling Tickets

Cashier → **New Sale** →

- Pick member (optional) — search one field, 500ms debounce.
- **Bulk tickets:** set count 1–12, grouped × count.
- **Products:** searchable combobox (or scan barcode).
- Total auto-calculated → Pay → ticket generated (grouped display lines).

Ticket = entry QR. Member child auto-selected for discount.
