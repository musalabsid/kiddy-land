# Reports

Owner → **Reports** →

- **Date range** — pick From/To (exports use this range).
- **Live metrics** — occupancy, active members, low stock; refresh every 10s, ignore dates.
- **Breakdown** — revenue, deposits received/applied/refunded/held/forfeited, by package/product/member/payment method.
- **Advanced filters** — cashier, payment method, package, product, member IDs.
- **Export** — CSV or PDF of the selected range (works offline, local host). A toast confirms the download, or reports an error if it fails.

All data stays on the Host PC — no internet.
