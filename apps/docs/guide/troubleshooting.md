# Troubleshooting

**Host IP changed banner** → re-scan QR (see Network → Windows Static IP or Router Reservation to prevent).

**Camera not opening on desktop** → desktop never asks camera permission — scan on phone/tablet only. Or use manual token input.

**Phone shows untrusted cert** → tap Advanced → Proceed (self-signed local cert). Fingerprint shown in Host Overview matches server.

**"Venue in grace period — no entry"** → calendar closed, 60m grace, no admit.

**Low stock warning** → restock via Inventory → Counts.

Still stuck? Host Overview → **Check again**.
